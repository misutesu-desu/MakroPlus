PUT YOUR GGUF MODEL HERE

Copy your downloaded .gguf file into this models folder next to
MakroPlus.exe. No model installer or special filename is required.
No language model weights are included in the Makro+ ZIP.

One GGUF file: detected automatically when no model was selected.
Several GGUF files: choose one in AI model > Configure model > Browse GGUF.
Use Refresh models folder if you copied a file while the dialog was open.
Open models folder always opens the folder for this copy of the app.

You can also choose a model stored in another folder. A previously selected
missing file is not silently replaced; choose its new location explicitly.
Models selected here are saved with a portable models-relative path.

The model must be a chat/instruction GGUF supported by the bundled llama.cpp
runtime and fit your available memory. Do not rename a ZIP, safetensors or
other format to .gguf. Extract downloaded archives before selecting a file.

See ../USER_GUIDE.html for model setup, prompts and every app section.
